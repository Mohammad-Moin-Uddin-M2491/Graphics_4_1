## Open in Overleaf

1. Choose New Project > Upload Project and upload the supplied Overleaf ZIP.
2. Set main.tex as the main document and choose the pdfLaTeX compiler.
3. Recompile. A second LaTeX pass resolves the linked page references.
4. Download the compiled PDF.

If you prefer to copy and paste the LaTeX, copy main.tex and also upload the
figures directory. The screenshots cannot be reproduced by pasting text alone.

external fonts, network access or bibliography processor are required.

## Report contents

The checked PDF has 30 A4 pages, including cover, contents and references.
It contains 58 numbered figures (including comparison panels), plus the
cover image. There are 55 distinct figure files in this package.

- Complete 17-action schedule and illustrated contact sequence.
- Construction from cubes, spheres and explicit triangle meshes.
- Transformation matrices, hierarchy, pivot and inverse-transpose mathematics.
- Camera/viewing and perspective projection, including ray-to-screen checks.
- Implemented illumination equation, materials and a worked RGB calculation.
- Lighting presets, shadow mapping and matched shading comparisons.

- Program architecture, measured verification, demo plan and references.
